# Catálogo web ITAC

Catálogo público adaptable a móviles, con búsqueda, filtro, ficha de producto, carrito persistente, pedidos por WhatsApp y exportación a Excel.

Usa los datos de `Tabla de precios.xlsx`, IDs estables, imágenes originales recortadas con transparencia y el logo ITAC. WhatsApp: +57 315 251 0570.

El PDF muestra $1.270 por metro para encajes; la tabla Excel detalla valores entre $1.200 y $1.750. Se priorizaron los valores del Excel.

El workflow de GitHub Actions instala `gh-pages` y publica el `index.html` en la rama `gh-pages`.
